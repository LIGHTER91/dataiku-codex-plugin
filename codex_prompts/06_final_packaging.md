# Codex Prompt 06 — Final Packaging

Prepare the plugin for distribution.

Check:

- `plugin.json` valid.
- MCP JSON valid.
- skills valid.
- README complete.
- `docs/guides/INSTALLATION_GUIDE.md` complete.
- examples complete.
- tests passing.
- release notes generated.
- safe defaults.
- no secrets.
- version set.

Create:

- `CHANGELOG.md`
- `RELEASE_NOTES.md`
- `PACKAGING_CHECKLIST.md`

Do not publish automatically.
